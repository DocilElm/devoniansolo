# devoniansolo
addons to devonian for solo clearers

## Requirements
Have [Devonian](https://modrinth.com/mod/devonian) mod installed

## Adds the following feature options to Devonian
* FiftyPingDB changes your blocks broken by dungeon breaker to simulate that of a 50 ping player. this also has an option for respawned secrets to be that of a 50 ping player.
* NoRotate

## How to access the settings?
This mod injects itself into [Devonian](https://modrinth.com/mod/devonian) so its settings are inside of `/dv` (some) marked as "cheats" (in red)
